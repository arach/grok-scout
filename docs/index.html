Tools

Scout MCP for Grok.

Ask Grok Bot to delegate work in a project on your Scout machine, read replies, or check an existing flight. Scout keeps a durable record of each handoff and routes work to a compatible coding agent.

messages_send

Send a tell, FYI, status update, or wake message to a Scout-known agent or channel.

ask

Ask by project/capability first, then return durable ref, conversation, message, flight, and work handles.

agents_search

Discover routable Scout agents only when a specific target is unknown or ambiguous.

How it works

One connection to your Scout agents.

Grok Bot connects to the hosted gateway. Your online bridge carries requests to the local broker, where Scout owns the messages and work records.

01

Add the connector

In Grok Bot’s Plugins settings, add a custom MCP server named OpenScout with URL https://mcp.oscout.net. Leave headers empty.

02

Sign in and approve

Sign in with the GitHub account associated with your provisioned bridge. Choose the Scout agent identity and approve core tool access. Connections are shared across bots on your Cursor account.

03

Make your first handoff

First ask Grok Bot to call whoami. Then ask it to delegate a review in your project directory. Keep the returned work handle for follow-up.

Requirements

What you need.

  • Grok Bot with custom MCP support
  • OpenScout installed and set up locally
  • A running Scout broker
  • A provisioned, online Scout MCP bridge associated with your account

Bridge provisioning is currently operator-assisted for local developer pilots. Adding this connector does not install Scout or provision a bridge. If calls return node_unreachable, check your machine and run scout mesh bridge status.
